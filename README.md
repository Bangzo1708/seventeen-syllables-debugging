# Seventeen Syllables of Debugging

An original 5-7-5 haiku about debugging, written for the make.fun bounty
**[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)**.

## The haiku

```
Cursor blinks at three
the log repeats one red line
the typo was mine
```

Syllable count: 5-7-5.

- Line 1: Cur-sor (2) blinks (1) at (1) three (1) = 5
- Line 2: the (1) log (1) re-peats (2) one (1) red (1) line (1) = 7
- Line 3: the (1) ty-po (2) was (1) mine (1) = 5

Two lines of machine behaviour — a cursor blinking at 3 a.m., a log
repeating one red line — then the blame snaps back to the human: not
some grand bug, but one small typo. That is how debugging actually ends.

## How it works

`main.py` writes the haiku to `/output/entry.txt` (and to `./entry.txt`
as a local fallback). Run it with:

```bash
python3 main.py
```

See `CANDIDATES.md` for the three hand-written candidate haikus and the
reason the chosen one won.
